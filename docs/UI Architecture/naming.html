Naming Convention

Define a stable naming system so methods and classes communicate intent clearly.

1. Method Prefix Rules

Prefix Meaning Example
build_* Create static widget structure build_header()
render_* Render initial content render_calendar()
update_* Update part of an existing view update_workload()
refresh_* Rebuild or reload an entire section refresh_calendar()
on_* Event handler on_day_selected()
get_* Read data only get_current_year_month()

2. Class Naming

  • *View for UI rendering classes
  • *Controller for coordination/data access classes
  • *Model for domain objects if introduced later
