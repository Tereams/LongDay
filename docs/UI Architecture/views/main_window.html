Main Window

The Main Window is the central coordinator between the Controller and all Views.

It is responsible for:

  • Requesting data from the Controller
  • Updating application state via the Controller
  • Coordinating multiple views
  • Distributing data to views
  • Handling user interactions from views

Responsibilities

  • Data Access: communicates with Controller
  • State Update: triggers changes in Controller
  • View Coordination: manages MainView and sub-views
  • Window Management: opens additional windows (e.g. TaskDetailWindow)

Data Flow (Core)

Data always flows downward:

Controller → MainWindow → MainView → Sub Views

Events always flow upward:

User → View → MainView → MainWindow → Controller

Example: Change Month

User clicks "Next"
→ CalendarView.on_next()
→ MainView.on_next_month()
→ MainWindow.on_next_month()

→ Controller.next_month()

→ MainWindow.render_calendar()
→ MainView.render_calendar()
→ CalendarView updates UI

Example: Select Day

User clicks a day
→ CalendarView.on_day_clicked(day)
→ MainView.on_day_selected(day)
→ MainWindow.on_day_selected(day)

→ Controller.get_day_schedule(day)

→ MainWindow.render_day_detail()
→ MainView.render_day_detail()
→ DayDetailView updates UI
