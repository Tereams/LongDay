1. Windows and Views

The GUI is structured into two main layers: Windows and Views.

Windows are the top-level containers that appear as visible regions on the screen. They define the layout and act as holders for different parts of the interface.

Views define how content is organized and displayed within a window. They are responsible for rendering UI elements and handling presentation logic.

In this design, windows contain views, and views determine how the interface is structured inside each window.

A useful analogy is:
Windows are like rooms, while views are the internal structures and arrangements within those rooms.

View Structure (Main Window)

The Main Window contains a top-level view called MainView, which is responsible for organizing the primary layout of the application. 

    MainView
    ├── PlanInputView
    ├── CalendarView
    └── DayDetailView

Each sub-view is responsible for a specific part of the interface:

  • PlanInputView: displays tasks and constraints
  • CalendarView: displays the monthly calendar
  • DayDetailView: shows detailed information for the selected day
